# Chase The Train

一个面向铁路迷的简洁 Web 项目。当前阶段提供 Next.js UI 基础、后端可行性结论和产品规格。

## 本地运行

```bash
npm install
npm run dev
```

开发与构建使用 Turbopack。部署到 Vercel 时，使用仓库根目录和 `npm run build`。
